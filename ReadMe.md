# Bank Account Management System

## Description

This project is a bank account management system written in C++. The program allows users to create and manage bank accounts through a menu-driven interface.

## Features

- Create a bank account
- View account information
- Deposit money
- Withdraw money
- Store multiple bank accounts
- Validate user input

## Files

- `BankAccount.h` - Contains the declaration of the BankAccount class.
- `BankAccount.cpp` - Contains the implementation of the BankAccount class.
- `main.cpp` - Contains the menu-driven program and user interaction.
- `ReadMe.md` - Contains documentation for the project.

## How to Run

1. Open the project in CLion.
2. Build the project.
3. Run the program.
4. Use the menu to create and manage bank accounts.
